# Customer Churn Prediction

A binary classification Machine Learning project that predicts whether a telecom customer is likely to leave a service provider.

## Objective
Identify customers at risk of churn using customer demographics, account information and service usage.

## Dataset
IBM Telco Customer Churn dataset.

- 7,043 customers
- 20 input features after removing customerID
- Target: Churn (Yes/No)
